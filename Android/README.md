# Finglish Android test project

This is intentionally a bare Android Studio project. It has no activity,
WebView, website clone, or Android app behavior.

1. Open this `Android/` folder in Android Studio.
2. Let Gradle sync and install any missing SDK components.
3. Open **Device Manager**, create an Android Virtual Device, and start it.
4. Open Chrome in the emulator and visit:

   `https://finglish.mehrashojjat.com/`

The project exists only to give Android Studio a local project alongside the
existing `iOS/` project. Website testing happens in the emulator's browser.
